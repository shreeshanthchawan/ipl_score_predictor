About the experiment

What was done

Ball-by-ball IPL data were combined into one total for each batter in each match. For every eligible batting appearance, the five earlier batting-appearance scores were used as input features and the runs in the current appearance were used as the target.

  • Baseline: predicts the average training-set score.
  • Linear Regression: uses the five previous scores to estimate the next score.
  • Random Forest: combines multiple decision trees to model non-linear patterns in the five scores.
  • Evaluation: a chronological split keeps later match dates for testing.
How to read the prediction: the estimate is for the player's next recorded batting appearance. The dataset cannot predict whether a player will be selected or get an opportunity to bat.
Limitations

What the prediction leaves out

The model only receives five previous scores. It does not know the player's batting position, opposition, pitch, venue, match conditions, playing XI, injuries or whether the player will bat. A single score can also be affected by an early dismissal or an unusually long innings. The prediction is an estimate, not a guaranteed score.

Data: supplied IPL ball-by-ball dataset, covering records through 3 June 2025. See the repository README and references for data and software details.
