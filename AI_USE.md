# AI-use disclosure

ChatGPT was used to assist with planning the data-processing workflow, drafting and debugging Python code, building the browser-based prediction interface, and preparing project documentation. The uploaded IPL CSV file was used as the data source. Model metrics and prediction outputs were generated by running the Python training script on that data.

The student is responsible for reviewing the implementation, verifying the dataset attribution, understanding the modelling choices and explaining the results during the project evaluation.
